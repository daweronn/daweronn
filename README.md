# David Felicio
### Desenvolvedor de Software Fullstack

> *A complexidade reduzida à sua forma mais simples.*

Desenvolvedor de software especializado nos ecossistemas JavaScript/TypeScript e Python. Possuo experiência consolidada na construção de aplicações end-to-end, com autonomia para atuar em todo o ciclo de desenvolvimento — desde a orquestração de infraestrutura em nuvem até a implementação de interfaces performáticas de alta conversão.

Minha atuação é direcionada à resolução de desafios críticos de negócio por meio da criação de arquiteturas *offline-first*, integrações *serverless* e engenharia de software rigorosa, priorizando sempre a entrega de código limpo, escalável e manutenível.

---

### Atuação e Competências

* **Arquitetura Fullstack:** Estruturação de sistemas complexos utilizando Next.js, React, Node.js e Python.
* **Cloud & Serverless:** Gerenciamento de infraestrutura escalável e segura utilizando recursos da AWS (S3, IAM).
* **Aplicações Desktop:** Construção de softwares multiplataforma de alta performance com o framework Tauri.
* **Design e UX:** Desenvolvimento de interfaces de usuário minimalistas e responsivas com TailwindCSS e CSS nativo.
